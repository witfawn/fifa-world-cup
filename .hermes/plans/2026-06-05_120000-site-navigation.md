# Bangers WC 2026 — Site Navigation & Structure Plan

## Goal
Design the complete site navigation, home page, prediction flow, leaderboard, and results display for the Bangers WC 2026 prediction game. Mobile-first, dark theme with gold accents.

## Current State
- **Pages:** /login, / (home), /predict, /profile, /auth/verify
- **Home page:** Simple greeting + profile nudge, no real content
- **Predict page:** 3 view modes (Upcoming, By Group, All Games), auto-save, scroll wheel picker
- **Navigation:** None — predict page only accessible via direct URL
- **Database:** users, accounts, sessions, match_predictions tables
- **Schedule:** 72 group stage matches in schedule.json

## Proposed Navigation Structure

### Bottom Tab Bar (Mobile)
Fixed bottom navigation with 4 tabs:

| Icon | Label | Route | Description |
|------|-------|-------|-------------|
| 🏠 | Home | `/` | Dashboard with status, upcoming matches, quick links |
| ⚽ | Predict | `/predict` | Match predictions (current page) |
| 🏆 | Leaderboard | `/leaderboard` | User rankings and points |
| 👤 | Profile | `/profile` | User settings, avatar, phone |

**Why bottom tab bar:**
- Standard mobile pattern (Instagram, Twitter, etc.)
- Always visible, one-tap access
- No hamburger menu needed
- Works great on phones (primary device)

### Top Header (All Pages)
Consistent header across all pages:
- Left: Trophy icon + "Bangers WC 2026"
- Right: Avatar (tap to go to profile)
- No sign-out button in header (move to profile page)

## Scoring Logic (for reference)

### Group Stage
```typescript
function calculateGroupPoints(predicted: {home: number, away: number}, actual: {home: number, away: number}): number {
  const predDiff = predicted.home - predicted.away;
  const actDiff = actual.home - actual.away;
  
  // Exact score
  if (predicted.home === actual.home && predicted.away === actual.away) return 10;
  
  // Correct goal difference
  if (predDiff === actDiff) return 7;
  
  // Correct winner (or both drew)
  const predWinner = predDiff > 0 ? 'home' : predDiff < 0 ? 'away' : 'draw';
  const actWinner = actDiff > 0 ? 'home' : actDiff < 0 ? 'away' : 'draw';
  if (predWinner === actWinner) return 5;
  
  // No match
  return 0;
}
```

### Knockout Stage
```typescript
function calculateKnockoutPoints(predicted: {home: number, away: number}, actual: {home: number, away: number}, winner: string): number {
  const predDiff = predicted.home - predicted.away;
  const actDiff = actual.home - actual.away;
  
  // Correct winner
  const predWinner = predDiff > 0 ? 'home' : predDiff < 0 ? 'away' : null;
  const actWinner = actDiff > 0 ? 'home' : actDiff < 0 ? 'away' : winner;
  
  let points = 0;
  if (predWinner === actWinner) points += 10;
  
  // Exact score (after 90/120 min)
  if (predicted.home === actual.home && predicted.away === actual.away) return points + 6;
  
  // Correct goal difference + winner
  if (predDiff === actDiff && predWinner === actWinner) return points + 4;
  
  return points;
}
```
